# SKU · HF-Scarf-01 节奏佩斯利·剪纸版

**英文名**：Rhythm Paisley Cut  
**系列**：Hippie-Funk-Memphis S1  
**调色板**：Palette A「Matisse 舞台」

---

## 1. 产品故事（中文）

排练室镜子前，我把头巾折成三角——佩斯利还在流动，却被三条 Funk 斜带切成节拍。Matisse 的红叶压在蓝带上，像把舞台灯光穿在身上；边缘 Mondrian 的断续网格，是乐谱里的休止符。这不是复古滤镜，是把 **波斯纹样、黑人 Funk 节奏和现代主义色面** 缝在同一块布上的小型宣言。

## 3. 图案说明（Printer-Ready）

### 3.1 画布

- 尺寸：650 × 650 mm  
- 出血：四周各 5 mm  
- 分辨率：300 dpi  
- 色彩模式：CMYK + 10 Spot（preferred）

### 3.2 分层结构

| Layer | 名称 | 内容 | 色值 |
|-------|------|------|------|
| L0 | Base | 满版米白 | `#F4F1DE` |
| L1 | Paisley | 连续佩斯利；线 0.4pt `#BC6C25`；填充 `#DDA15E` @85% | — |
| L2 | Funk Bands | 45° 平行四边形带；宽 18/12/22mm | `#E9C46A` `#E056FD` `#1E6FD9` |
| L3 | Matisse Leaves | 5 片有机叶，实心无描边 | `#E63946` `#40916C` `#1E6FD9` 轮换 |
| L4 | Memphis Dots | Terrazzo Ø2–4mm，12%/cm² | `#FF6B6B` `#4D96FF` |
| L5 | Rhythm Grid Border | 距边 3cm 内框；线 1.8mm | `#1A1A1A`；格比 1:1.6:2.4 |

### 3.3 对位要点

- L2 斜带 **必须切断** L1 Paisley 流线，不得柔化羽化  
- L3 叶形 **压在上** L2，允许 10% 面积重叠  
- L4 **禁止** 落在 L2 中心线 ±5mm  
- L5 仅在距边 3–6cm 环带内；中心区域留白呼吸

### 3.4 文化来源（吊牌 80 字）

佩斯利源于波斯/南亚纺织；斜向色带致敬美国 Funk 舞台视觉；色块叶形来自 Matisse 剪纸；边饰网格受 Mondrian 新造型主义启发之「节奏网格」再设计；碎点提取 Memphis 派撞色语法。

## 4. 三种绑法 × 场景

### 绑法 A · 额前三角（排练室）

| 步骤 | 操作 |
|------|------|
| 1 | 对折成三角，长边绕后脑 |
| 2 | 两角在额前打结，露出 **Matisse 红叶** 于眉上 |
| 3 | 可选抽绳在颈后收紧，固定碎发 |

**场景**：排练室、镜前试音 — 符号：专注、节奏  
**露出图案**：L3 红叶 + L2 蓝带  
**搭配**：白背心 + 牛仔 + `HF-Ear-01` 耳饰

### 绑法 B · 低马尾包裹（地铁通勤）

| 步骤 | 操作 |
|------|------|
| 1 | 折成宽 8cm 长条 |
| 2 | 从额后经耳上绕至低马尾，结于颈侧 |
| 3 | 让 **Funk 斜带** 横贯太阳穴位置 |

**场景**：地铁、通勤 — 符号：城市游牧、低调撞色  
**露出图案**：L2 芥末+品红带  
**搭配**：深色夹克，耳饰单色块朝外

### 绑法 C · 颈巾垂坠（天台日落）

| 步骤 | 操作 |
|------|------|
| 1 | 松松围颈，结于锁骨前 |
| 2 | 一角垂胸，展示 **节奏网格饰边** |
| 3 | 风大时抽绳系于腕或包带 |

**场景**：天台、日落、音乐节前奏 — 符号：自由、宣言  
**露出图案**：L5 饰边 + L4 Memphis 点  
**搭配**：吊带裙 / 工装裤；全身照用于小红书图 5–6
