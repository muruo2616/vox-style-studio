# 场景卡 × 3 · Hippie-Funk-Memphis S1

每张卡遵循：**场景 → 产品用法 → 价值意义 → 拍摄要点**

---

## 场景卡 01 · 排练室镜前

| 字段 | 内容 |
|------|------|
| **场景** | 地下排练室，砖墙 + 单面镜，下午侧光 |
| **产品用法** | 头巾 **绑法 A**（额前三角）；耳饰红叶朝镜头；可选抽绳固定碎发 |
| **价值意义** | 「上场前的自我对齐」— 配饰是仪式而非装饰 |
| **穿搭** | 白背心、运动裤、旧帆布鞋 |
| **拍摄** | 半身镜前；焦点额前 Matisse 红叶；F2.0 浅景深 |
| **文案钩子** | 「切分音系在额头上。」 |
| **公式** | `formulas.md` #1 |
| **文化源** | Funk 排练室文化；Matisse 色面作为心理「提色」 |

## 场景卡 02 · 地铁车窗

| 字段 | 内容 |
|------|------|
| **场景** | 晚高峰地铁，车窗反光，城市霓虹掠过 |
| **价值意义** | 「城市游牧者的低调徽章」— 不喧哗的撞色 |
| **产品用法** | 头巾 **绑法 B**（低马尾包裹）；耳饰 Mondrian 色块朝外 |
| **穿搭** | 黑色风衣、耳机绕颈、托特包 |
| **拍摄** | 侧脸剪影 + 车窗反光双重人像；强调斜带 `#E9C46A` `#E056FD` |
| **文案钩子** | 「车厢里最小的广告牌。」 |
| **公式** | `formulas.md` #2 |
| **文化源** | 嬉皮城市流徙；Memphis 碎点 = 信息过载里的节奏点 |

## 场景卡 03 · 天台日落

| 字段 | 内容 |
|------|------|
| **场景** | 屋顶天台，日落暖光 + 城市天际线 |
| **价值意义** | 「把天空穿成可携带的色块」— 自由与预告夜场 |
| **产品用法** | 头巾 **绑法 C**（颈巾垂坠）；耳饰双点下垂；抽绳可系腕 |
| **穿搭** | 吊带连衣裙或宽松工装裤；赤脚或马丁靴 |
| **拍摄** | 全身广角；风吹起垂坠角，露出 **节奏网格饰边** |
| **文案钩子** | 「日落被剪成叶子形状。」 |
| **公式** | `formulas.md` #3 |
| **文化源** | Matisse 剪纸与天空色面；Mondrian 边饰 = 乐谱休止 |
