# SKU · HF-Ear-01 剪纸滴坠·叠点

**英文名**：Cut-Out Drops Stack  
**系列**：Hippie-Funk-Memphis S1  
**设计方向**：**Matisse 有机剪纸镂空** + Mondrian 色块嵌件 + Memphis 双点 — 与头巾同 Palette A

> 耳饰选 **一条连贯方向**：主形态 Matisse 叶形滴坠；节奏与撞色由 Mondrian 微嵌件 + Memphis 点完成，避免三种风格平均用力。

---

## 1. 产品故事（中文）

头巾上的红叶太大，我把它剪下来挂在耳边——镂空里是空气，外面是 Matisse 的平涂勇气。耳垂下两粒 Memphis 的碎点，像舞台返听里漏出的高频。轻到忘记戴着，但侧脸一转，撞色就在。

## 2. 规格 Specs

| 项目 | 参数 |
|------|------|

## 3. 结构分解（打样用）

```
        [钛钢耳针 + 硅胶背堵]
                 |
        [连接环 Ø3mm 钛钢]
                 |
    ┌────────────────────────┐
    │  MAT-LEAF 镂空滴坠      │  28×20mm 外轮廓
    │  内嵌 MON 12×8 矩形色块 │  红/黄/蓝 各一 cell
    └───────────┬────────────┘
                │
         [MEM 圆点 Ø4mm ×2]
         珊瑚 + 电蓝 垂距 3mm
```

### 3.1 矢量要求

- 提供 SVG：外路径闭合；内嵌矩形公差 +0.1mm  
- 镂空最小桥宽：**1.2 mm**（防断）  
- 表面：正面哑光，背面磨砂去反光

### 3.2 与头巾配对逻辑

| 头巾层 | 耳饰呼应 |
|--------|----------|
| Matisse 红叶 `#E63946` | 主叶同色 |
| Matisse 蓝 `#1E6FD9` | 连接环电镀蓝（可选） |
| Mondrian 节奏网格 | 12×8mm 三色嵌件 |
| Memphis Terrazzo | 底部双 Enamel 点 |

---

## 4. 佩戴与护理

- 适合：单戴或 **左右不对称**（左叶红 / 右叶蓝，限量玩法）  
- 避免：香水直接喷洒；游泳、桑拿  
- 清洁：干布擦拭；Enamel 忌酒精  

---

## 5. 文化来源（吊牌）

主轮廓取自 Matisse 剪纸有机形；嵌件致敬 Mondrian 原色构成；坠点提取 Memphis Group 碎点撞色 — 与头巾 HFM 图案同源异构。

- 套装卡：头巾绑法 B + 本耳饰 = 「地铁撞色公式」（见 `formulas.md`）
