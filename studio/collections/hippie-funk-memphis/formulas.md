# 搭配公式 · Mood × Color × Pairing

> 每条公式含：**情绪** + **色组** + **头巾绑法 + 耳饰朝向** + **文化一句**

---

## 公式 1 · 排练室切分音

| 维度 | 内容 |
|------|------|
| **Mood** | 专注、热身、镜前对话 |
| **Color** | 主：`#E63946` 红叶 + `#1E6FD9` 蓝带；辅：`#F4F1DE` 留白 |
| **Pairing** | 绑法 A 额前三角 + 耳饰红叶朝前 + 白背心/黑色运动bra |
| **文化源** | Funk 切分音视觉 → 斜带切断 Paisley |
| **一句话** | 「让额头成为第二舞台。」 |

## 公式 2 · 地铁撞色游牧

| 维度 | 内容 |
|------|------|
| **Mood** | 通勤、低调但可被辨认 |
| **Color** | 主：`#E9C46A` + `#E056FD` 斜带；点：`#FF6B6B` |
| **Pairing** | 绑法 B 低马尾包裹 + 耳饰 Mondrian 色块朝外 + 深色丹宁/风衣 |
| **文化源** | 嬉皮「城市游牧」+ Memphis 碎点高频 |
| **一句话** | 「车厢里最小的色块广告牌。」 |

## 公式 3 · 天台 Matisse 日落

| 维度 | 内容 |
|------|------|
| **Mood** | 自由、预告夜场、风与光 |
| **Color** | 主：`#40916C` 叶绿 + `#E63946`；边：`#1A1A1A` 网格饰边 |
| **Pairing** | 绑法 C 颈巾垂坠 + 耳饰双点下垂 + 吊带/工装 + 金属腰带 |
| **文化源** | Matisse 色面解放 + Mondrian 边饰休止 |
| **一句话** | 「把日落切成色块戴在锁骨上。」 |

## 公式 5 · 单色克制（转化向）

| 维度 | 内容 |
|------|------|
| **Mood** | 怕撞色过猛的入门用户 |
| **Color** | 仅露 `#1E6FD9` + `#F4F1DE`；其余卷起隐藏 |
| **Pairing** | 绑法 B 仅露蓝带 + 单只耳饰 + 全黑上衣 |
| **文化源** | Mondrian 留白原则 |
| **一句话** | 「撞色也可以只开一盏灯。」 |
