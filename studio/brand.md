# VOX Style Studio · 品牌内核

> **产品主导的设计工作室** — Season 1 仅头巾 + 耳饰，以乐队主唱 / 亚文化穿搭博主的个人 IP 为叙事载体，服务小红书种草与 IP 引流。

---

## 1. 品牌定位

| 维度 | 定义 |
|------|------|
| **品类** | 配饰（头巾、耳饰）；Season 1 不做眼镜 |
| **风格主线** | Hippie × Funk，本季叠加 Matisse / Mondrian / Memphis 艺术抽象 |
| **审美关键词** | 高饱和撞色、节奏感纹样、可佩戴的「平面构成」 |
| **方法论** | 文化/语境 → 抽象元素（色/纹/形/材）→ 产品功能（用法/搭配）→ 场景 + 价值意义 |
| **渠道语气** | 小红书产品首图 + IP 旁白；拒绝泛化 OOTD 堆砌 |

---

## 2. IP 人设（叙事层，非 SKU）

- **身份**：独立乐队主唱；长期记录亚文化穿搭与现场文化
- **声音**：直接、有节奏感；用「排练室 / 后台 / 地铁月台」等真实场景锚定产品
- **价值**：配饰是「把态度戴在头上、挂在耳边」的便携宣言，而非跟风单品

## 3. 四条风格轨（Style Rails）

全系列可在四条轨间切换或混搭，**本季主推轨 4**：

| 轨 | 名称 | 文化源 | 产品气质 |
|----|------|--------|----------|
| **R1** | 游牧平面 | 60–70s 反战嬉皮、自然主义、手工染 | 大地色底 + 有机轮廓；柔软、可叠戴 |
| **R2** | 节奏 Funk | 非裔美国 Funk 视觉与音乐节奏（见伦理注记） | 斜向色带、高对比、身体律动线 |
| **R3** | 构成主义饰边 | Mondrian 式节奏网格、现代主义平衡 | 结构化绑法、几何耳饰呼应 |
| **R4** | **后波普撞色** ★ | Matisse 剪纸色块 + Memphis 几何戏谑 | **高饱和撞色、印花可量产** |

> Season 1 集合名：`hippie-funk-memphis` — 在 R1+R2 基础上，用 R4 艺术参考拉高饱和度与识别度。

## 4. Funk 文化伦理注记（必引）

Funk 音乐与视觉语言根植于 **20 世纪非裔美国社区** 的自我表达、舞蹈文化与政治韧性。本工作室在借用斜向色带、律动分割与「身体即乐器」等视觉语法时：

- **做**：标注文化来源；在文案与产品说明中致敬 Funk 先驱（如 James Brown、Parliament-Funkadelic 一脉的视觉遗产）
- **不做**：将 Funk 降格为「复古滤镜」或无来源的「潮酷条纹」；不与殖民化挪用式嬉皮符号简单拼贴而不说明

所有 Pattern 对外发布须附带 **文化来源一句**（见各 SKU 与 `.cursor/rules/product-led.mdc`）。
