## 一、判决性检验：权重公式（最重要）

### 1.1 争议

| | 模型主公式（v0.2.4） | 培训 PPT 第 17 页文字 |
|---|---|---|
| 专业能力 | 40% | 40% |
| 职业素养 | 30% | 30% |
| 社会声誉 | **10%** | **20%** |
| 现金盈余 | **20%** | **10%** |

PPT 正文写「权重分别为 40%、30%、20%、10%」（声誉 20%、现金 10%）。但**平台排行榜表头**直接印着 `社会声誉(10%)`、`现金盈余(20%)`，与 PPT 正文相反。

### 1.2 全样本逐行重算（不是抽样）

对 16 份回合 PDF 第 1 页排行榜的每一行（专业、素养、声誉、现金、总分），用两套公式分别重算，与平台给出的总分比对（容差 0.06）：

```
候选排行榜数据行：     138 行
主公式(声誉10/现金20) ：138 / 138 命中  ✓
PPT版(声誉20/现金10) ： 43 / 138 命中
其中“PPT 也命中”的 43 行，全部是“社会声誉 = 现金盈余”导致两式数值相同的偶合；
没有任何一行只满足 PPT 版而不满足主公式。
```

典型样本（主公式精确、PPT 偏差明显）：

```
85.84×.4 + 86×.3 + 70×.1 + 100×.2 = 87.14（平台 87.14）  PPT 算得 84.14 ✗
80.00×.4 + 80×.3 + 40×.1 +  90×.2 = 78.00（平台 78.00）  PPT 算得 73.00 ✗
85.54×.4 + 86×.3 +100×.1 + 100×.2 = 90.02（平台 90.02）  PPT 算得 90.02（声誉=现金，偶合）
```

### 1.3 判决

**主公式（专业40/素养30/声誉10/现金20）正确，PPT 第 17 页正文权重为笔误/排版错误。** v0.2.4 对此的处理（废弃 PPT 版、保留主公式、表头佐证）完全正确，本报告将证据强度从原 15 行升级为 **138 行 / 138 命中**。

> 实战含义：**现金权重 = 声誉权重的 2 倍**。宁可少抢一案保住现金，也不要为冲声誉而透支现金。

## 四、新发现的已验证规则（v0.2.5 新增）

### 4.1 行政费 = 工资支出 × 10%（恒定）

逐份核对四个场次的经营页：

```
章铭  ：工资 326,166 → 行政 32,616  （326,166 × 10% = 32,616.6）
蔡巧蛾：工资 257,250 → 行政 25,725  （×10% 精确）
王建国：工资 360,600 → 行政 36,060  （×10% 精确）
维尔德：工资 111,000 → 行政 11,100  （×10% 精确）
```

**这是 v0.2.4 未明确写出的规则。** 写入后，现金预测可在赛中口算（不必等系统出账）。已加入模型 §5.1 与说明书 §零「现金速算」。

## 六、仍存在的局限（暂不武断修改，列为已知边界）

1. **竞争得分子权重未知**：PPT 第 16 页仅定性列出「商务洽谈 + 服务方案 + 报价 + 社会声誉」，平台未公开各子项权重，报价亦不在排行榜公开。模型 §6.6 的经验权重为方向性估计，不应当作精确公式。
2. **助理对办案容量的贡献未量化**：维尔德 Rank1 仅 2 名律师却夺冠，提示助理或案件难度对实际容量有影响；负载模型为启发式，赛中以「不超时、固定案先做完」为硬约束更稳。
3. **熟练度为主观输入**：折减系数依赖自评熟练度，建议赛前用样题校准各人熟练度档位，减少临场分歧。
4. **样本来自单一届次材料**：138 行足以确证权重公式，但策略阈值（期望值 80、承接分 75 等）仍属经验值，非平台公开参数。
