## 第三届核心变化（v0.3.0）

```text
6 竞争案           → 5 竞争案
贴近均价报价        → 低价有利但不亏本（成本安全价 × 折扣系数 1.10~1.35）
竞标因素           + 团队配置、基本专业能力
社会声誉           + 市场营销影响（受现金约束）

```

被实测确立、跨届保留的硬规则：

```text
权重主公式 40/30/10/20（138/138 验证；第三届首轮再核验）
预计现金 = 期初/结转现金 + 业务收入 − 工资×1.10 − 招聘费 − 培训费 − 营销费

固定案先占负载；R2不招聘/R3补缺不扩张/R4不冲刺；现金为负即破产
```
