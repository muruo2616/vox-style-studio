### 材料总览

回合一文件夹共 10 个 PDF，全是云实训知识模块，不涉及经营模型：

| 文件 | 主题 | 负责人 |

| 产品自损案型中的产品责任 | 侵权/消费者 | 法务A |

| 离职一年内职务发明 | 知产/劳动交叉 | 经营C |

### 操作步骤

```
步骤1：组长打开平台，进入回合一云实训
步骤2：每道题 → 读题后喊出主题 → 对应负责人快速报关键词
步骤3：组长根据组员判断点选答案
步骤4：做到最后一步"小测验"，全部答完后提交
```

### 具体示例（以"我不是药神.pdf"为例）

**题目类型**：药品犯罪（刑事）

**法务B 的操作流程**（按 §10.1 刑事清单）：

```
身份关系 → 问：陆勇是什么身份？患者代购还是销售？
阶段      → 问：案件处于侦查/审查起诉/审判哪个阶段？
强制措施  → 问：是否被羁押？取保候审条件？
会见/阅卷 → 问：律师能否会见？能否阅卷？
证据合法性→ 问：药品是否属于"假药"？法律修订前后认定差异
伦理边界  → 问：律师在法益衡量中如何给出建议？
```

**五问复核**（组长提交前）：

```
一问伦理 → 律师是否可以建议当事人"法不责众"？
二问程序 → 案件管辖是否在药品犯罪专门法庭？
三问证据 → 印度药品是否属于刑法第141条"假药"？
四问事实 → 陆勇是否以营利为目的？
五问现金 → （回合一不适用）
```

### 回合一禁区

- ❌ 组员点击系统（仅组长操作）
- ❌ 讨论经营/报价/招聘（回合一不涉及）
- ❌ 跳过最后小测验（不做小测 = 放弃回合分）

## 二、回合二操作说明

### 场景设定

回合二是经营模型的第一回合。初始条件：

- 现金 60 万
- 律师 3 人 + 助理 3 人
- 市场提供 6 个竞争案源 + 1 个固定案源

### 材料中的实际案源

根据回合二 PDF 数据，本回合可能出现的案源：

**固定案**（系统分配，二选一）：

| 固定案 | 类型 | 负载 | 影响 |
|--------|------|------|------|
| 李建东故意伤害案 | 刑事普通程序 | 1.5 | R2 策略：抢 1 个民商/劳动竞争案 |
| 蔡巧娥杀人案 | 故意杀人 | 1.6～1.8 | R2 策略：抢 1 个民商案，不抢刑事竞争案 |

**竞争案**（6 个中可选择竞争）：

| 竞争案 | 类型 | 复杂系数 | 推荐度 |
|--------|------|----------|--------|
| 王秋雨劳务受害责任 | 民商事 | 1.0 | ★★★ 首选 |
| 迅捷安诉华屏（著作权） | 知识产权 | 1.2 | ★★☆ 熟练可抢 |
| 田某继承/房屋争议 | 民商事 | 1.0 | ★★★ 首选 |
| 丁光严等纠纷 | 民商/不明 | 1.0 | ★★☆ |
| 刘利民交通肇事 | 刑事 | 1.5 | ★☆☆ 不抢 |
| 陈金合同诈骗 | 刑事 | 1.5 | ★☆☆ 不抢 |

### 决策步骤（分场景走查）

#### 场景 A：固定案 = 李建东故意伤害案（负载 1.5）

**第 1 步：查分支表（§4.0）**

```
固定案类型：刑事普通程序 → 查表得：
  R2 策略 = 营销 1～2 万，抢 1 个民商/劳动案，不抢刑事竞争案
```

**第 2 步：算负载（§6）**

```
团队总上限 = 3 × 0.95 = 2.85
固定案预留 = 1.5
可竞争负载 = 2.85 - 1.5 = 1.35

可抢条件：竞争案负载 ≤ 1.35
→ 普通民商事（1.0 × 熟练度修正）≤ 1.35 ✓
→ 刑事（1.5 × 熟练度修正）≈ 1.43 > 1.35 ✗
```

**第 3 步：逐案打分（§7）**

以王秋雨劳务受害案为例：

```
承接分 = 熟悉度×0.35 + 人员充足×0.25 + 预期利润×0.20 + 时间可控×0.20
       = 85×0.35 + 80×0.25 + 75×0.20 + 80×0.20
       = 29.75 + 20 + 15 + 16 = 80.75

期望值 = 承接分×0.45 + 预计专业×0.30 + 预计现金×0.15 + 声誉×0.10
       = 80.75×0.45 + 80×0.30 + 75×0.15 + 70×0.10
       = 36.34 + 24 + 11.25 + 7 = 78.59 → 谨慎档（70～79）

实际判断：劳务受害是民商事标准案，模型公式偏保守。
建议上调到"优先抢"。
```

以刘利民交通肇事案为例（对照）：

```
承接分 ≈ 60（刑事程序风险 + 不熟悉交通肇事）→ <60
→ 红线封顶规则 §7.3 第 1 条：案件类型不熟 → 不抢
```

**第 4 步：经营决策（§5）**

```
安全现金线 ≈ 下回合固定成本 × 1.2
            ≈ (144,000 + 14,400) × 1.2  [3 律师 + 3 助理半年工资]
            ≈ 190,080

回合初现金 = 600,000
600,000 > 190,080 → 均衡档位

R2 营销 = 1～2 万（R2 特别规则：严禁超 3 万）
招聘    = 不招（R2 默认不招聘）
培训    = 不培训（R2 默认不培训）
```

**第 5 步：报价（§8）**

假设王秋雨案市场均价 25,000，成本底价 15,000：

```
报价可行条件：15,000 × 1.3 ≤ 25,000 × 1.03
             19,500 ≤ 25,750 → ✓ 可行

k = 0.98（声誉一般，适度贴近均价提高中标率）
最终报价 = max(19,500, 25,000×0.98) = max(19,500, 24,500) = 24,500
```

**第 6 步：预测回合末现金（§5.1）**

```
业务收入 ≈ 25,000（竞争成功案报价）
工资支出 = 144,000（3 律师 + 3 助理 × 6 个月）
行政费用 = 14,400（工资 × 10%）
市场营销 = 20,000
现金盈余 = 600,000(期初) + 25,000 - 144,000 - 14,400 - 20,000 = 446,600 ✓
```

**决策结论**：抢王秋雨劳务受害案（或田某继承案），营销 2 万，不招聘不培训。

#### 场景 B：固定案 = 蔡巧娥杀人案（负载 1.6～1.8）

**第 1 步：查分支表（§4.0）**

```
固定案类型：故意杀人 → 查表得：
  R2 策略 = 营销 0～1 万，抢 1 个高确定性民商案，绝不抢刑事竞争案
```

**第 2 步：算负载**

```
可竞争负载 = 2.85 - 1.6 = 1.25

更紧！只能抢 1 个民商事案（1.0 × 0.95 = 0.95 ≤ 1.25）✓
刑事竞争案（1.5 × 0.95 = 1.425 > 1.25）→ 绝对不抢
```

**第 3 步：经营**

```
R2 营销 = 0～1 万（比场景 A 更保守）
原因：杀人固定案负载高，执行时间更紧，不能分散精力
```

**决策结论**：抢 1 个最熟悉的民商案，营销 ≤1 万，不招聘不培训。

### 回合二反面案例（来自蔡巧蛾固定场经营页）

某队伍的实际经营数据：

```
律师从 3→5、助理从 3→6（招聘 5 人）
工资支出：257,250（vs 正常 144,000）
市场营销：88,888（vs 建议 10,000～20,000）
现金盈余：238,637（vs 正常 429,600～446,600）

教训：招聘 + 高营销吃掉了一半现金流
```

→ **这就是为什么模型规定 R2 不招聘、营销上限 3 万。**

## 三、回合三操作说明

### 场景设定

回合三是分水岭。从 PDF 数据看，此回合破产率高达 40～50%。

### 材料中的实际案源

**固定案**（全部分配同一类型）：

| 固定案 | 类型 | 负载 |
|--------|------|------|
| 李其生与五工公司、谢明杰追索劳动报酬纠纷 | 劳动争议 | 1.0 |

**竞争案**：

| 竞争案 | 类型 | 复杂系数 | 推荐度 |
|--------|------|----------|--------|
| 张家有纠纷 | 民商事 | 1.0 | ★★★ |
| 李佳戈与刘倩纠纷 | 民商事 | 1.0 | ★★★ |
| 田某继承 | 民商事 | 1.0 | ★★★ |
| 陈祖芬诉港湾 | 民商事/侵权 | 1.0 | ★★★ |
| 章铭销售有毒有害食品 | 刑事 | 1.5 | ★☆☆ 不抢 |

### 决策步骤

**第 1 步：查分支表（§4.0）**

```
固定案类型：劳动争议（劳动）→ 查表得：
  R3 策略 = 控制工资，补缺不扩张，抢 2 个左右
```

**第 2 步：检查人力资源**

```
回合初先核对系统实际离职人数 → 按缺口补缺
假设无离职：3 律师 + 3 助理 → 不招聘
假设离职 1 名助理：只补 1 名助理，不招律师

人员红线检查（§5.3）：3 律师 < 5 → 不触发红线 ✓
```

**第 3 步：算负载**

```
团队总上限 = 3 × 0.95 = 2.85
固定案预留 = 1.0（劳动争议）
可竞争负载 = 2.85 - 1.0 = 1.85

可抢条件：民商事竞争案 × 2（负载必须 ≤ 1.85）
  · 两案均高熟悉（熟练度≥90，折减0.85）：1.0×0.85 ×2 = 1.70 ≤ 1.85 → 可过 ✓
  · 两案仅标准熟悉（熟练度75～89，折减0.95）：1.0×0.95 ×2 = 1.90 > 1.85 → 略超 0.05
    → 处理：只抢 1 个稳妥案，或仅在两案确属高熟悉时才抢 2 个，不要凑数硬抢

若抢 3 个案：≈ 2.85 > 1.85 → 超载 ✗
```

**第 4 步：经营决策**

```
安全现金线 ≈ 170K～190K
R2 结束后现金盈余 ≈ 430K～446K（保守经营）
430K > 190K × 1.5 → 可考虑均衡/略进攻

R3 营销 = 1～2 万（均衡档）
招聘    = 仅补缺（离职才补）
培训    = 若有明确人力瓶颈且现金充足 → 可培训 ≤2K
```

**第 5 步：竞争案选择**

抢 2 个最熟悉的民商案。从 PDF 数据看：

```
实际中标竞争分参考（有限样本）：
  陈祖芬诉港湾：中标分 87～93
  田某继承：中标分 81～88
  李佳戈与刘倩：中标分 70～80

优先抢：陈祖芬 + 田某（或李佳戈，视熟悉度）
不抢：章铭（刑事 + 食品犯罪 ➜ 高危）
```

**竞争烈度提醒**（§6.6）：

```
R3 竞争分普遍 >85 → 报价 k 取 0.97～0.99，提高中标率
同时服务方案必须完整不缺项
```

**第 6 步：预测回合末现金**

```
假设抢 2 个案成功，各报价 25,000：
  业务收入 = 50,000
  工资支出 = 144,000
  行政费用 = 14,400
  市场营销 = 20,000
  现金盈余 = 430,000 + 50,000 - 144,000 - 14,400 - 20,000 = 301,600 ✓
```

### 回合三反面案例（来自章铭场经营页）

```
律师 7 人 + 助理 7 人 = 14 人（扩张失控）
工资支出：326,166
业务收入：25,800
市场营销：5
现金盈余：-48,637 → 破产风险！

崩盘链：R2 过度招聘 → R3 工资爆炸 → 即使零营销仍负现金流
```

→ **这就是为什么模型规定：每回合新增 ≤1 人 + 律师 ≥5 触发红线 + R2 不招聘。**

## 四、回合四操作说明

### 场景设定

终局回合。PDF 数据显示：回合四破产率极高，固定案类型决定生死。

### 材料中的实际案源

| 王宪化诉太平洋保险合同纠纷 | 保险合同（民商事） | 1.0 | 均衡/进攻 |
| 王建国故意杀人案 | 故意杀人 | 1.6～1.8 | **生存模式** |

**竞争案**：

| 竞争案 | 类型 | 复杂系数 | 推荐度 |
|--------|------|----------|--------|
| 张信实抵押合同纠纷 | 民商事 | 1.0 | ★★★ |
| 苗艳诉金某纠纷 | 民商事 | 1.0 | ★★★ |
| 台州维尔德公司纠纷 | 仲裁 | 1.2 | ★★☆ |
| 任安过失致人死亡 | 刑事 | 1.5 | ★☆☆ |
| 刘成辉洗钱案 | 刑事 | 1.5 | ★☆☆ |

### 场景 A：固定案 = 王宪化保险合同（负载 1.0）

**第 1 步：查分支表（§4.0）**

```
固定案类型：保险（普通民商事）→ 查表得：
  R4 策略 = 均衡/进攻，抢 1～2 个熟悉案
```

**第 2 步：生存模式检查（§4.0.1）**

```
条件 1：固定案为杀人/洗钱？否 → 不触发
条件 2：现金 < 安全线 × 0.5？假设 R3 后现金 ≈ 300K，安全线 ≈ 170K → 不触发
条件 3：律师 ≥ 6？假设仍为 3 人 → 不触发
→ 不进入生存模式，正常运营
```

**第 3 步：算负载**

```
团队总上限 = 3 × 0.95 = 2.85
固定案预留 = 1.0
可竞争负载 = 1.85

可抢 2 个民商事案（须两案均高熟悉）：
  熟练度≥90（折减0.85）：1.0×0.85 ×2 = 1.70 ≤ 1.85 → 可过 ✓
  熟练度75～89（折减0.95）：1.0×0.95 ×2 = 1.90 > 1.85 → 略超，只抢 1 个更稳
```

**第 4 步：经营决策**

```
R4 营销 = 2～3 万（进攻档，保险固定案有空间）
招聘    = 不招（R4 不为长期发展招聘）
培训    = 不培训（R4 培训无法在本回合产生回报）
```

**第 5 步：竞争案选择**

```
优先：张信实抵押合同（民商、高熟悉）
次选：苗艳诉金某（民商、高熟悉）
备选：台州维尔德仲裁（仲裁，熟练可抢）
不抢：任安过失致死（刑事）、刘成辉洗钱（刑事 + 高危）
```

**第 6 步：预测**

```
假设抢 2 个案成功，各报价 25,000：
  业务收入 = 50,000
  工资支出 = 144,000
  行政费用 = 14,400
  市场营销 = 30,000
  现金盈余 = 300,000 + 50,000 - 144,000 - 14,400 - 30,000 = 161,600 ✓

目标总分参考（类似场景实际样本）：
  专业 85 + 素养 86 + 声誉 100 + 现金 100 → 总分 ≈ 90
```

### 场景 B：固定案 = 王建国故意杀人案（负载 1.6～1.8）

**第 1 步：进入生存模式**

```
触发条件 1：固定案为故意杀人 且 回合 = 4 → 触发！

生存模式规则：
  ✅ 不招聘、不培训
  ✅ 营销 0～1 万
  ✅ 不抢刑事/高负载竞争案
  ✅ 仅在现金安全且负载允许时，最多抢 1 个低负载高熟悉民商事案
  ✅ 全力保专业能力 + 职业素养
```

**第 2 步：算负载**

```
团队总上限 = 3 × 0.95 = 2.85
固定案预留 = 1.6～1.8
可竞争负载 = 2.85 - 1.6 = 1.25（非常紧张）

最多抢 1 个民商事案：1.0 × 0.95 = 0.95 ≤ 1.25 ✓
抢 2 个：1.90 > 1.25 → 超载 ✗
```

**第 3 步：经营**

```
R4 营销 = 0～1 万（生存模式最低档）
招聘/培训 = 0

重点：杀人案固定案本身是高程序风险 + 高负载
     执行时间可能超预期 → 不要分心抢竞争案
     70% 权重在专业能力 + 职业素养 → 把固定案做对！
```

**第 4 步：竞争案选择**

```
如果现金安全（≥安全线）且负载允许 → 最多抢 1 个：
  选：张信实抵押合同（民商、低负载、高熟悉）
  不选：任何刑事案（任安、刘成辉触发生存模式禁令）

如果现金紧张或时间紧 → 不抢任何竞争案
  仅执行固定案（王建国故意杀人）→ 保底策略
```

### 回合四反面案例（来自王建国场经营页）

```
律师 9 人
工资支出：360,600
业务收入：60,000
市场营销：10,000
现金盈余：-286,042 → 破产！

问题：
  1. 律师 9 人 → 严重违反 §5.3 人员上限（≥6 禁招）
  2. 回合四应进入生存模式 → 但团队仍在运营
  3. 固定案是杀人案 → 应该精简而非扩张
```

## 五、完整回合决策流程速查卡

打印此页，赛时放在手边。

### 开局（前 2 分钟，经营C + 组长）

```
□ 确认回合号：R1 / R2 / R3 / R4
□ （R2～R4）看系统分配的固定案名称 → 判断类型 → 查分支表定策略
□ 核对回合初人力资源（实际律师数 + 助理数 + 离职）
□ 算：可竞争负载 = 律师人数 × 0.95 - 固定案预留负载
□ 算：安全现金线 ≈ (现有工资 + 行政费) × 1.2
□ 定档位：防守 / 均衡 / 进攻 / 生存模式
```

### 运营（第 2～10 分钟，经营C 主责）

```
□ R1：跳过运营
□ R2：营销 1～2 万（严禁 >3 万），不招聘，不培训
□ R3：按离职补缺，不扩张，营销 1～2 万
□ R4：
    ▶ 保险/民商固定案 → 营销 2～3 万，不招聘不培训
    ▶ 杀人/洗钱固定案 → 营销 0～1 万，不招聘不培训（生存模式）
□ 律师 ≥5 → 红线复核；律师 ≥6 → 禁止招聘
□ 预测回合末现金 > 0
```

### 竞争（第 10～20 分钟，全员）

```
对每个竞争案依次判断（用下表）：

 案名 | 类型 | 负载 | 承接分 | 期望值 | 红线 | 报价可行 | 抢？
------|------|------|--------|--------|------|----------|-----
 ... | ... | ... | ...  | ...  | ... | ...   | ...

走查顺序：
  1. 查分支表 → 本回合最多抢几个？
  2. 案源类型优先级：民商 > 仲裁 > 劳动 > 刑事
  3. 按承接分排序，从高到低评估
  4. 负载检查：Σ已选竞争案负载 ≤ 可竞争负载
  5. 期望值检查：≥80 可抢，70～79 有余力再抢
  6. 红线检查：8 条红线逐一对照
  7. 报价：max(底价×1.3, 均价×k)
  8. k 值：声誉领先 0.98～1.00，声誉落后 0.97～0.99
  9. 最后一次：预测抢案后现金盈余 ≥ 安全线
```

### 执行（第 20～57 分钟，法务A/B + 组长）

```
执行顺序：固定案 → 竞争成功案

单案管线：
  法务A 读题/归纳事实（20% 时间）
  → 组长确认法律关系正确
  → 法务B 定证据/程序/文书（40% 时间）
  → 组长点选提交
  → 复核（15% 时间）

刑事案：身份→阶段→强制措施→会见/阅卷→证据→伦理
民商事：主体→合同/侵权→请求权→证据链→风险告知→报价
仲裁案：仲裁协议→机构→材料→仲裁庭→裁决/撤裁/执行
劳动案：身份→劳动事实→工资/工伤证据→法援/收费规范
```

### 收尾（最后 3 分钟，组长）

```
五问复核（每案必问）：
  1. 伦理：有无利益冲突、保密违规、不当承诺？
  2. 程序：管辖、时效、主体是否无误？
  3. 证据：证据表是否完整、分类是否正确？
  4. 事实：事实归纳是否准确、无遗漏？
  5. 现金：提交前确认不会触发破产

倒计时前主动提交，绝不等到系统强制提交。
```

## 六、常见陷阱与应对

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 开局就想多抢案 | R2 抢 3～4 个竞争案 | 查分支表 → 负载上限拦住 → 严格执行 |
| 觉得人不够就招聘 | R2 招 2 律师 3 助理 | R2 招聘禁令 → 先做固定案再判断 |
| 营销无上限 | 营销 5～9 万 | R2 上限 3 万，其余按档位 |
| 刑事案看起来简单 | 交通肇事、洗钱等 | 查类型优先级 → 刑事永远排最后 |
| 回合四冲刺心态 | 抢所有刑事竞争案 | 查生存模式 → 不抢刑事 |
| 现金分 100 就放松 | 全场破产时 -286K 也能排第一 | 看绝对值不看排名分 |
| 固定案没做完就抢案 | 超时强制提交 | 固定案永远第一优先级 |
| 报价太低抢案 | 为了中标报离群低价 | 报价公式：max(底价×1.3, 均价×k) |
