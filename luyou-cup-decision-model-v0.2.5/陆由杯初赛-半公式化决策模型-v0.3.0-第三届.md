用途：将每回合选择固定为可重复流程，减少临场争论。

## 1. 权重与总分公式

### 1.1 主公式（默认）

```text
总分 = 专业能力×0.40 + 职业素养×0.30 + 社会声誉×0.10 + 现金盈余×0.20
```

### 1.2 ~~培训 PPT 版权重~~ → 培训材料曾出现，已被实测排除（**非备选公式**）

```text
~~总分 = 专业能力×0.40 + 职业素养×0.30 + 社会声誉×0.20 + 现金盈余×0.10~~
```

> ⚠ 经实测证伪：平台报告表头直接显示「社会声誉(10%)、现金盈余(20%)」，与 PPT 培训版（声誉20%、现金10%）相反；独立复核对 16 份报告共 138 行排行榜数据逐行重算，主公式 138/138 命中、PPT 版 0 行独立命中。**实战只有一个公式（§1.1 主公式）**，PPT 版仅作为「培训材料曾出现但已被实测排除」的历史说明，不再作为任何意义上的备选。

### 1.3 实测结论

四回合排行榜数据**全部匹配主公式**。独立复核（见《独立复核与完善报告 v0.3》）从 16 份回合 PDF 中逐行提取 138 行排行榜数据重算：主公式 **138/138 命中**（误差 ≤0.06）；PPT 版仅在「社会声誉=现金盈余」的 43 行偶然重合，**无任何一行只满足 PPT 版**。示例：

```text
85.84×0.40 + 86×0.30 + 70×0.10 + 100×0.20 = 87.14
85.54×0.40 + 86×0.30 + 100×0.10 + 100×0.20 = 90.02
```

实战只使用主公式。

不变结论：

```text
专业能力 + 职业素养 = 70%
案件做对 > 盲目抢案 / 压价 / 扩张
高分 ≈ 能做完的案源数 × 正确率 × 低价不亏本报价 × 不破产
```

### 1.4 第三届首轮强制复核

第三届 PPT 与第二届实测存在权重冲突，开赛后必须当场验证：

```text
① 第一份排行榜出来后，任取 2～3 行（含已知四项分与总分）
② 用主公式重算：专业×0.40 + 素养×0.30 + 声誉×0.10 + 现金×0.20
③ 若与平台总分吻合（误差<0.1）→ 继续用主公式（大概率）
④ 若不吻合，再试 PPT 版：声誉×0.20 + 现金×0.10；以吻合者为准
⑤ 一旦确认，立即口头同步全组，后续回合不再争论
```

## 2. 组内分工与角色 KPI

```text
组长   = 操作提交 + 时间控制 + 最终拍板
法务A  = 事实归纳 + 法律关系判断（5W）
法务B  = 证据分类 + 程序节点 + 文书纠错
经营C  = 报价 + 招聘/营销 + 现金流 + 负载/期望值
```

| 角色 | 本回合达标标准 |
|---|---|
| 组长 | 不漏提交、不超时、不超承载 |
| 法务A | 事实表正确、法律关系正确 |
| 法务B | 证据分类正确、程序节点正确、文书纠错正确 |
| 经营C | 现金为正、报价不离群且不低于成本底线、案源不超载 |

单案流水线：

```text
法务A 归纳事实 → 法务B 定证据/程序/文书 → 组长点选提交
竞争阶段由经营C同步盯报价、现金和负载
```

提交前五问：

```text
一问伦理，二问程序，三问证据，四问事实，五问现金。
```

单案质量自评：

```text
单案质量 ≈ 正确率×60% + 速度×20% + 完整度×20%
```

原则：时间紧也不牺牲法律关系、证据、程序、伦理。

## 3. 按回合总决策链

```text
① 确认回合：回合一只跑知识模块；回合二至四跑经营模型
② 识别固定案类型，预留固定案负载
③ 算团队能力×0.95，得到可竞争负载
④ 算现金安全线，确定防守/均衡/进攻档位
⑤ 控制招聘、培训、营销预算
⑥ 对每个竞争案算承接分、期望值、报价可行性
⑦ 只抢：负载合规 + 期望值≥80 + 未触红线 + 报价可行
⑧ 执行顺序：固定案 → 竞争成功案 → 高把握任务
⑨ 五问复核：伦理 → 程序 → 证据 → 事实 → 现金
```

## 4. 回合差异化策略

### 4.0 固定案类型 × 回合分支表

同一回合，固定案类型不同 → 策略完全不同。回合开始必须第一时间识别固定案类型，查下表：

| 固定案类型 | 负载 | R2 策略 | R3 策略 | R4 策略 |
|-----------|------|---------|---------|---------|
| 普通民商事 / 劳动 / 保险 | 1.0 | 营销 1～2 万，默认抢 1 个高确定性竞争案 | 控制工资，补缺不扩张，抢 2 个左右 | 均衡/进攻，抢 1～2 个熟悉案 |
| 仲裁 / 证据较多 | 1.2 | 营销 1～2 万，抢 1 个熟悉案 | 控制工资，抢 1～2 个 | 均衡，抢 1 个熟悉案 |
| 刑事普通程序（故意伤害等） | 1.5 | 营销 1～2 万，抢 1 个民商/劳动案，不抢刑事竞争案 | 控制工资，抢 1～2 个优先民商 | 防守/均衡 |
| 故意杀人 / 洗钱 / 毒品犯罪 | 1.6～1.8 | 营销 0～1 万，抢 1 个高确定性民商案，绝不抢刑事竞争案 | 控制工资，抢 1 个优先民商，不抢刑事竞争 | **→ 进入生存模式** |

### 4.0.1 生存模式

```text
触发条件（任一即触发）：
  1. 固定案为故意杀人/洗钱/毒品犯罪 且 回合 = 4
  2. 回合初现金盈余 < 安全线 × 0.5
  3. 律师人数 ≥ 6

生存模式规则：
  不招聘、不培训
  营销 0～1 万
  不抢刑事/高负载竞争案
  仅在现金安全且负载允许时，最多抢 1 个低负载高熟悉民商事案
  全力保专业能力 + 职业素养（70% 权重靠做题质量）
  目标：不破产 + 保底分数
```

### 4.1 回合策略速查

| 回合 | 核心策略 | 禁忌 |
|------|---------|------|
| 回合一 | 云实训知识模块，走完流程并完成最后小测 | 跑经营模型、组员代点 |
| 回合二 | 保守开局，固定案预留后按分支表抢案 | 早期大招聘、高营销、多抢刑事案 |
| 回合三 | 补缺优先，控制工资，谨慎扩张 | 为了案量盲目加人 |
| 回合四 | 终局稳分，不为长期发展招聘，不超载冲刺；高危固定案进入生存模式 | 最后一轮猛扩张、重营销、硬抢高危刑事案 |

### 4.2 回合一知识分工

回合一 PDF 材料覆盖认罪认罚、产品责任、凶宅买卖、合同成立、药品犯罪、股权、著作权、涉外仲裁、职务发明等主题。回合一不算承接分、不算报价、不做招聘，只做知识模块。

```text
组长：流程推进 + 小测提交
法务A：民商事、合同、侵权、产品责任、股权
法务B：刑事、刑诉、认罪认罚、药品犯罪、主体身份
经营C：仲裁、知产、劳动/职务发明、涉外执行，并记录高频错题
```

回合一流程：

```text
读题 → 定领域 → 找关键词 → 五问复核 → 小测提交
```

## 5. 现金流与经营决策

### 5.1 基础公式

```text
现金盈余 = 期初现金 + 业务收入 − 工资 − 招聘费 − 培训费 − 行政费 − 市场营销费
  期初现金：R2 = 60 万；R3/R4 = 上一回合的「现金盈余」结转
  行政费  = 工资支出 × 10%（四回合 16 份报告逐份验证，恒为 10%，可直接用于现金预测）
```

**赛中口算式**（把行政费折进工资，一步算出预计现金）：

```text
预计现金 = 期初/结转现金 + 业务收入 − 工资×1.10 − 招聘费 − 培训费 − 营销费
```

### 5.2 底线

```text
回合末现金盈余 > 0
安全现金线 = 下回合预计固定成本 × 1.2
```

现金为负会触发破产风险；现金低于安全线时进入防守。

### 5.3 招聘

```text
招聘 YES ⇔ 预计新增案件收入 > 新员工总成本×1.5
          且 新员工在本回合或下一回合能产生实际承接能力
招聘 NO  ⇔ 否则
```

新增人员优先补缺，不优先扩张。每回合新增人员默认 ≤1 人；若需新增 2 人以上，必须同时满足：

```text
1. 现金 ≥ 安全线×1.5；
2. 固定案 + 目标竞争案负载超过现有人力；
3. 预计新增案件收入 > 新员工总成本×1.5；
4. 本回合或下一回合能实际产生承接能力。
```

人员上限提醒（从 R2 开始每回合检查）：

```text
若律师人数 ≥5，新增律师须触发红线复核；
若律师人数 ≥6，原则上禁止继续招聘，除非现金≥安全线×2 且期望值≥90。
```

### 5.4 培训

```text
培训 YES ⇔ 专业/素养收益 > 培训支出对现金盈余的损失
```

回合 2 默认不培训；回合 3～4 在现金 ≥ 安全线且有人力瓶颈时再考虑。

### 5.5 营销预算上限

```text
营销预算上限 = min(当前安全现金余额×0.25, 预期业务收入×0.50)
```

无法快速计算时用默认档：

| 档位 | 营销默认值 |
|---|---|
| 防守 | 0～1万 |
| 均衡 | 1万～2万 |
| 进攻 | 2万～3万 |
| 极特殊高确定性案源 | 最多 5万，须组长确认 |

测试报告中出现过高营销导致现金接近危险区的样本，因此禁止无上限营销。

**R2 营销特别规则：** 无论回合档位，R2 营销默认 1～2 万，严禁超过 3 万。R2 现金是后续三回合的底仓。

### 5.6 回合档位

| 档位 | 条件 | 招聘 | 营销 | 抢案 |
|---|---|---|---|---|
| 防守 | 盈余 < 安全线 | 不招 | 0～1万 | 固定案 + 最多 1 个高确定性竞争案 |
| 均衡 | 安全线 ≤ 盈余 < 安全线×1.5 | 满足招聘公式才招 | 1～2万 | 负载合规 + 期望值≥80 |
| 进攻 | 盈余 ≥ 安全线×1.5 且人力足 | 满足招聘公式可招 | 2～3万 | 可略增案量，但必须负载合规 |

防守档位允许抢 1 个竞争案，但必须同时满足：期望值≥80、负载合规、报价可行、竞争后现金仍不破产且不进一步破坏安全线。

## 6. 团队办案能力、固定案预留与案件负载

### 6.1 核心公式

```text
团队办案能力 = 有效办案人数 × 单人处理能力
团队总上限   = 团队办案能力 × 0.95
固定案预留负载 = 根据固定案类型先扣除
可竞争负载   = 团队总上限 − 固定案预留负载
竞争案总负载 = Σ(竞争案数量 × 修正复杂系数)
可抢条件     = 竞争案总负载 ≤ 可竞争负载
```

口径说明：**有效办案人数按律师人数计**（律师助理提供事实/证据/文书支援，但不单独计入负载容量上限）；单人处理能力默认取 1。

v0.2.3 的关键改动是：固定案必须先占负载。测试中回合二、三、四的固定案可能是杀人、故意伤害、劳动报酬、保险合同等，不能把团队全部能力都拿去算竞争案。

### 6.2 固定案预留负载

| 固定案类型 | 预留负载 |
|---|---:|
| 普通民商事 / 劳动 / 保险 | 1.0 |
| 仲裁 / 证据较多 | 1.2 |
| 刑事普通程序 | 1.5 |
| 故意杀人、洗钱、药品/食品犯罪等高危刑事 | 1.6～1.8 |

### 6.3 基础复杂系数

| 类型 | 系数 |
|---|---:|
| 法律援助 / 固定流程 | 0.8 |
| 普通民商事 | 1.0 |
| 仲裁 / 证据较多 | 1.2 |
| 刑事 / 高程序风险 | 1.5 |

### 6.4 熟练度修正

```text
修正复杂系数 = 基础复杂系数 × 熟练度折减系数
```

| 熟练度 | 折减系数 |
|---|---:|
| ≥90 | 0.85 |
| 75～89 | 0.95 |
| 60～74 | 1.00 |
| <60 | 1.20 |

### 6.5 示例

```text
有效办案人数 = 3，单人能力 = 1
团队总上限 = 3×0.95 = 2.85
固定案为刑事普通程序，预留 1.5
可竞争负载 = 2.85 − 1.5 = 1.35

若竞争普通民商事 1 案，熟练度 85：
竞争负载 = 1.0×0.95 = 0.95，可抢

若再加仲裁 1 案，熟练度 90：
新增负载 = 1.2×0.85 = 1.02
竞争总负载 = 1.97 > 1.35，超载，不抢
```

### 6.6 竞争分构成（定性说明）

竞标竞争力 ≈ 商务洽谈 + 服务方案 + 低价优势 + 社会声誉 + 团队配置 + 基本专业能力
（第三届 PPT 第 25 页明确列出的竞标影响因素；具体权重平台未公开，以下为经验方向）：

| 分量 | 提分关键 |
|------|---------|
| 商务洽谈 | 先听后说 → 先确认后建议；伦理/保密/收费规范类回答是隐性加分 |
| 服务方案 | 方案完整度（不缺项）> 引用相关案例 > 突出律师团队专业匹配 |
| 报价（低价优势） | **报价越低竞争得分越高，但非决定性因素**；在不亏本、不破坏现金安全线前提下尽量压低（详见 §8） |
| 社会声誉 | 办案累积声望 + 律所市场营销投入 的综合；多回合累计，单案内难操控 |
| 团队配置 | 律师/助理数量与结构匹配案件需要；人手不足或冗余都会扣分 |
| 基本专业能力 | 律所既有专业能力基数（回合一测评 + 历史办案）直接影响竞标 |

经验阈值（非硬规则，基于有限样本）：

```text
竞争分 ≥85：高概率中标
80～84：有竞争力
70～79：不稳定，需要运气
<70：低概率中标
```

报价公式只解决竞争分的一部分。商务洽谈和服务方案靠专项清单（§10）和五问复核（§2）提分。

## 7. 案源竞争：承接分、期望值与红线

### 7.1 承接分：判断「接不接得住」

```text
承接分 = 熟悉度×0.35 + 人员充足×0.25 + 预期利润×0.20 + 时间可控×0.20
```

| 承接分 | 含义 |
|---|---|
| ≥75 | 能力上可积极竞争 |
| 60～74 | 谨慎 |
| <60 | 不抢 |

### 7.2 案源期望值：判断「值不值得抢」

```text
案源期望值 = 承接分×0.45 + 预计专业得分×0.30 + 预计现金贡献×0.15 + 声誉贡献×0.10
```

| 期望值 | 决策 |
|---|---|
| ≥80 | 优先抢，且必须通过负载、现金、报价、红线检查 |
| 70～79 | 有余力再抢 |
| <70 | 不抢 |

### 7.3 红线封顶规则

出现以下任一情况，案源期望值最高封顶 69，一律不抢：

1. 案件类型完全陌生；
2. 固定案预留后，竞争案总负载超出可竞争负载；
3. 预计报价低于成本安全价（即亏本）；
4. 竞争该案后预测回合末现金盈余低于 0，或低于安全现金线；
5. 队内无人能快速判断核心程序；
6. 现金紧张却只能靠降价才能博中标（此时应少抢案，而非压价硬抢）；
7. 新增人员或营销投入会使本回合进入破产风险；
8. 回合四仍需要为长期发展而招聘。

第 4 条用于修正防守档位：不是「现金低于安全线就绝对不能抢」，而是看抢该案后是否进一步破坏安全现金或导致破产。

### 7.4 类型优先级

```text
普通民商事 → 仲裁（负载允许）→ 法律援助 → 刑事（熟且负载允许）→ 高危复杂案
```

回合四终局优先：保险合同、抵押合同、买卖合同/仲裁等高熟悉民商事案；谨慎选择洗钱、故意杀人、过失致人等刑事高程序案。

## 8. 报价算法（第三届：低价有利，但绝不亏本）

第三届 PPT 第 25 页：**报价越低，案源竞争得分越高，但价格不是决定性影响因素。**
因此从第二届的「贴近均价」改为「低价优势 + 成本安全底线」：

```text
报价策略 = 在不亏损、不破坏现金安全线的前提下，尽量降低报价
最终报价 = 成本安全价 × 折扣利润系数
```

- 成本安全价：覆盖该案直接成本（人力工时 + 行政摊销）的最低不亏本价；
- 折扣利润系数：>1 的薄利系数，越接近 1 报价越低、竞争分越高，但利润越薄。

| 档位 | 折扣利润系数 | 说明 |
|---|---|---|
| 现金紧张 | —（不降价抢案，**少抢案**） | 现金优先，不靠压价博中标 |
| 防守 | 1.25～1.35 | 留足利润垫，保现金 |
| 均衡 | 1.15～1.25 | 适度让利提高中标率 |
| 进攻 | 1.10～1.20 | 现金充裕时可贴近成本安全价压价抢案 |

红线：报价低于成本安全价（亏本）一律不报；现金紧张时不靠降价抢案，改为少抢。

口诀：

```text
低价有利中标，但绝不亏本抢案。
```

## 9. 时间分配公式

### 9.1 回合 2～4：60 分钟

防守 / 均衡：

```text
运营 : 竞争 : 执行 : 复核 = 8 : 10 : 37 : 5
```

进攻：

```text
运营 : 竞争 : 执行 : 复核 = 9 : 12 : 34 : 5
```

### 9.2 案件执行内部

```text
读题/事实 20% | 法律关系 25% | 作答/文书 40% | 复核 15%
```

### 9.3 时间不够时

固定案与已竞争成功案必须完成。  
压缩低把握复杂任务的非关键推演时间，例如反复讨论、反复翻材料。  
优先保证：伦理题、程序题、证据表、事实表、必填项。  
不能放弃已承接案件。

### 9.4 回合 1

45 分钟，组长操作；云实训 + 最后小测验提交；无经营、无抢案；组员只口头支援，不点击。

## 10. 案件类型专项清单

### 10.1 刑事案

```text
身份关系 → 阶段 → 强制措施 → 会见/阅卷 → 证据合法性 → 伦理边界
```

重点：故意杀人、故意伤害、交通肇事、洗钱、药品/食品犯罪均属高程序风险；不熟时宁可少抢。

### 10.2 民商事案

```text
主体 → 合同/侵权关系 → 请求权基础 → 证据链 → 风险告知 → 报价
```

重点：保险合同、抵押合同、买卖合同、劳务受害、继承/房屋争议通常适合稳分，但证据表和事实表必须正确。

### 10.3 仲裁案

```text
仲裁协议 → 仲裁机构 → 申请材料 → 仲裁庭 → 裁决/撤裁/执行
```

重点：仲裁类程序化强，熟练队伍可优先；不熟时容易在管辖、材料、文书称谓上丢分。

### 10.4 劳动 / 法援案

```text
身份关系 → 劳动事实 → 工资/工伤/报酬证据 → 法援/收费规范
```

重点：职业素养和风险告知收益较高，适合稳分。

### 10.5 知识产权 / 股权 / 涉外

```text
权利归属 → 授权/登记/合同 → 侵权或履行事实 → 管辖/执行 → 证据
```

重点：回合一知识模块中出现较多，适合赛前专题速记。

## 12. 单回合执行清单

开局：

- 确认回合类型：回合一知识模块；回合二至四经营模型；
- 确认主公式 / 保守备选；
- 识别固定案类型并预留负载；
- 算安全现金线、档位；
- 算团队总上限与可竞争负载。

运营：

- 按回合 2/3/4 策略决定招聘、培训、营销；
- 检查新增人员上限；
- 检查营销预算上限；
- 预测回合末现金盈余 > 0。

竞争：

- 每案计算承接分、期望值、修正负载；
- 检查固定案预留后是否仍有可竞争负载；
- 检查红线；
- 检查报价可行条件；
- 报价使用：`成本安全价 × 折扣利润系数`（防守1.25~1.35 / 均衡1.15~1.25 / 进攻1.10~1.20）。

执行：

- 固定案 → 竞争成功案 → 按优先级处理；
- 法务A → 法务B → 组长提交；
- 时间不够按第 9.3 条压缩讨论，不放弃已承接案件。

收尾：

- 五问：伦理 → 程序 → 证据 → 事实 → 现金；
- 倒计时前主动提交，避免系统强制提交。

## 附录：比赛结构速记

| 项目 | 内容 |
|---|---|
| 回合 1 | 45 分钟云实训，组长操作，小测必交 |
| 回合 2～4 | 各 60 分钟：运营 → 竞争 → 执行 |
| 初始资源 | 60 万；律师 3 + 助理 3 |
| 案源 | 每回合 5 个竞争案源 + 1 个固定案源（第三届 PPT 第 16/17 页，由 6 下调为 5） |
| 破产 | 现金盈余 < 0，后续不可竞争案源 |
| 平台 | https://www.luyouor.com |

> ⚠ **现金盈余分 ≠ 账户安全**：排行榜上现金盈余 100 分仅表示本场次相对最高，不表示现金绝对安全。当全场普遍破产时，少量正现金也可能排第一名。始终以现金盈余绝对值 > 安全现金线为判断依据，不以分数为准。

> 📋 **离职规则**：每回合初先核对系统实际离职人数，按缺口补缺；预估时按 0～1 人保守预留，不写死公式。

> 📈 **回合间结转**：现金盈余与社会声誉跨回合累积（PPT「特别注意事项」第 1 条：每一回合得分对后续回合都有影响）。现金盈余直接结转为下回合期初现金（见 §5.1），声誉为多回合累计效应。因此 R2/R3 切忌为短期分数透支现金或人力——前期稳健 = 后期更高的现金安全垫与声誉基数。

> 🎲 **回合一案例随机**：第三届回合一案例为案例库随机抽取，赛前按领域广覆盖复习，不押单一题型。

> 🤖 **AI 智能体环节观察项**：第三届设有「人工智能法学智能体应用」环节（PPT 第 3 页），但 PPT 第 5 页写明「初赛总得分=软件平台操作最终得分」，故初赛模型**暂不为 AI 智能体单独计分**；若后续通知该环节计入初赛，须单独增设策略。

> 🔢 **案源池缩小为 5**：竞争案由 6 降为 5，候选更少。抢案上限同步从严（分支表中的「抢 1～2 个」即为相对 5 案池的上限），优先保熟悉、保现金，不为凑数硬抢。
