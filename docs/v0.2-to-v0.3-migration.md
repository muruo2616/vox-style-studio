## 2. `data/components.json`  schema

零部件地图的数据源，与网页内 `COMPONENTS_DATA` 同源（embedded 或 fetch）。

```json
{
  "version": "0.3",
  "updated": "2026-05-25",
  "categories": [
    { "id": "actuation", "name": "传动执行", "order": 1 }
  ],
  "components": [
    {
      "id": "reducer",
      "name": "谐波/行星减速器",
      "category": "actuation",
      "plainExplanation": "…",
      "whyItMatters": "…",
      "routes": ["electric", "industrial"],
      "typicalUsage": "…",
      "valueConfidence": "中-高",
      "relatedCompanies": ["leader", "shuanghuan"],
      "keyRisks": ["ASP 下行"],
      "plainRisks": "…",
      "evidenceStatus": "verified | reported | inferred | pending"
    }
  ]
}
```

**字段说明：**

| 字段 | 用途 |
| --- | --- |
| `id` | 稳定标识，与公司 `componentIds` 关联 |
| `category` | 六类分组键，对应 `categories[].id` |
| `plainExplanation` | 非专业读者一句话解释 |
| `whyItMatters` | 对产业判断的意义 |
| `routes` | 关联技术路线（electric / bionic / service 等） |
| `valueConfidence` | BOM 价值量置信度（非财务预测） |
| `relatedCompanies` | `companies` 数组中的 `id` 列表 |
| `evidenceStatus` | 与 §0 证据分级对齐 |

当前版本含 **15 个零部件**（reducer · torque-motor · leadscrew · hollow-cup-motor · force-sensor · tactile-sensor · vision-3d · controller · edge-compute · structure · thermal · oem-assembly · myofiber · micro-hydraulic · polymer-bone）。

## 4. §6 公司列表分组（v0.3.1）

v0.3.1 将 §6 公司图谱从旧版**模块 filter 卡片 grid** 改为**六类投资分组列表**：

| 分组 `companyGroup` | 筛选按钮 `data-group` | 含义 |
| --- | --- | --- |
| `oem` | 整机厂 | 本体/品牌方 |
| `component` | 核心零部件 | 减速器、电机、传感等 |
| `oem_structure` | 代工与结构件 | 立讯、拓普、三花等 |
| `software` | 软件·平台 | 控制器、边缘算力、视觉 |
| `watch` | 观察池 | 叙事强、验证弱 |
| `weak` | 弱叙事 | 低置信映射 |

**列表行（5 字段）：** 公司名/代码 · 路线 · 环节（`componentIds` → `segmentLabel`）· 证据 pill · 一句话摘要。

**详情展示：**

| 视口 | 行为 |
| --- | --- |
| `≥1024px` | 左侧列表 + 右侧 `#company-drawer` 抽屉 |
| `<1024px` | `#company-modal` 全屏弹窗 |

旧 `#company-grid` 保留 DOM 但 `hidden`；`renderCompanies()` 与 `.filter-tab` 模块筛选已移除。

**双向跳转：**

- 公司详情内 `.comp-tab-jump[data-comp-id]` → `setV3Tab('components')` + 滚动 `#tab-components-map`
- 零部件卡片 `.comp-co-jump[data-co]` → `setV3Tab('companies')` + `showCompanyDetail` + 滚动 `#s6`
- 气泡图点击 → `showCompanyDetail`

`loadComponentsData` 成功后会调用 `refreshComponentNameMap`，刷新列表行的环节列与详情内零部件名称。

## 5. Tab 视图 vs 线性视图

| 模式 | 触发 | 行为 |
| --- | --- | --- |
| **Tab 视图**（默认） | 无参数 | 仅显示当前 Tab 的 `.v3-panel.v3-visible` |
| **线性视图** | `?view=full` | 忽略 Tab 过滤，全部 section 可见 |

Tab 切换通过 `body.v3-tab-mode` + `.v3-panel` / `.v3-visible` 控制，**不删除 DOM**，图谱/里程碑/组合等交互脚本仍在页面加载时初始化。
