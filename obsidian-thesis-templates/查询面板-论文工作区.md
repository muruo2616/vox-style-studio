# 查询面板 · 论文工作区

本页集中放 Dataview 查询。需启用 **Dataview** 插件。

---

## 问题一 · 适用范围

关注 `违法类型`、`争点` 字段。

---

## 问题二 · 决定衔接与同案异决

关注 `结案方式`、`是否同案异决`。

---

## 问题三 · 结案与救济

关注 `结案方式` 为调解书、和解撤回的条目。

---

## 一、案例总表（按章节）

```dataview
TABLE 违法类型, 结案方式, 争点, 来源
FROM "案例矩阵"
WHERE file.name != this.file.name
SORT 章节 ASC, 违法类型 ASC
```

---

## 二、同案异决清单（已标记）

```dataview
TABLE 违法类型, 结案方式, 对比案例, 同案异决说明
FROM "案例矩阵"
WHERE 是否同案异决 = true
SORT 违法类型 ASC
```

---

## 三、按违法类型分组（找「同类不同结案」）

> 人工查看：同一 `违法类型` 下是否出现多种 `结案方式`。

```dataview
TABLE 案例简称, 结案方式, 争点, 章节
FROM "案例矩阵"
WHERE 违法类型 != null
SORT 违法类型 ASC, 结案方式 ASC
```

---

## 四、处罚类案件 · 变更 vs 调解书 vs 撤回

```dataview
TABLE 案例简称, 结案方式, 争点, 对比案例
FROM "案例矩阵"
WHERE contains(违法类型, "处罚") OR contains(违法类型, "行政处罚")
SORT 结案方式 ASC
```

---

## 五、许可 / 依据违法类案件

```dataview
TABLE 案例简称, 结案方式, 争点, 来源
FROM "案例矩阵"
WHERE contains(违法类型, "许可") OR contains(违法类型, "依据")
SORT 结案方式 ASC
```

---

## 六、拟写入第4章的案例

```dataview
TABLE 违法类型, 结案方式, 争点
FROM "案例矩阵"
WHERE contains(章节, "4") OR contains(章节, "第四章") OR contains(章节, "决定衔接")
SORT 违法类型 ASC
```

---

## 七、文献笔记 · 待读

```dataview
TABLE author, year, journal, 章节关联
FROM "文献笔记"
WHERE status = "未读"
SORT year DESC
```

---

## 八、文献笔记 · 已读待引用

```dataview
TABLE author, year, 章节关联, tags
FROM "文献笔记"
WHERE status = "已读" OR status = "已引用"
SORT 章节关联 ASC
```

---

## 九、文献按章节关联

```dataview
TABLE author, year, status
FROM "文献笔记"
WHERE 章节关联 != null
GROUP BY 章节关联
```

---

## 十、本周新建笔记

```dataview
LIST
FROM "案例矩阵" OR "文献笔记" OR "政策规范"
WHERE file.ctime >= date(today) - dur(7 days)
SORT file.ctime DESC
```

## 使用提示

1. **同案异决**：录入案例时在 frontmatter 设 `是否同案异决: true`，并填 `对比案例: "[[另一案例名]]"`。
2. **违法类型** 建议统一用语，例如：`行政处罚-内容不适当`、`行政许可-依据违法`、`程序违法-重大`。
3. **结案方式** 建议统一：`调解书`、`变更决定`、`和解撤回`、`确认违法`、`撤销`、`其他`。
4. 若查询为空，检查文件夹名是否为 `案例矩阵`、`文献笔记`（与库内路径一致）。
