# 5 分钟安装步骤

## 1. 复制到 Obsidian 库

将 `obsidian-thesis-templates` 文件夹内**全部内容**复制到你的库根目录，例如：

`C:\Users\sjlov\Documents\论文-行政复议调解\`

## 2. 启用插件

Obsidian → 设置 → 社区插件 → 开启：

- **Templater**
- **Dataview**
- **Zotero Integration**（若已装 Zotero + BBT）

## 3. 配置 Templater

设置 → Templater：

| 项 | 值 |
|----|-----|
| Template folder location | `templates` |
| Trigger Templater on new file creation | 可选开启 |

建议命令（设置 → 热键）：

| 命令 | 建议快捷键 |
|------|------------|
| Templater: Create new note from template | `Ctrl+Alt+N` |

## 4. 新建案例/文献笔记

1. 在 `案例矩阵` 文件夹右键 → 新建笔记
2. `Ctrl+P` → 输入 `Templater: Create new note from template`
3. 选 **案例条目** 或 **文献笔记**
4. 填写 frontmatter（**争点、违法类型、结案方式** 务必填，否则 Dataview 表是空的）

## 5. 打开查询面板

打开库根目录的 `查询面板-论文工作区.md`，若看到示例两行（某酒店/某超市），说明 Dataview 正常。

## 6. 字段用语表（建议统一）

### 违法类型

- `行政处罚-内容不适当`
- `行政处罚-事实不清`
- `行政处罚-程序违法`
- `行政许可-依据违法`
- `行政许可-程序违法`
- `行政协议-履行/违约`
- `履职-不作为`

### 结案方式

- `调解书`
- `变更决定`
- `和解撤回`
- `确认违法`
- `撤销`
- `撤回申请终止`
- `维持/驳回`

### 章节

- `第3章` / `第4章` / `第5章`（或写 `适用范围` `决定衔接` `程序与救济`）

## 7. Hermes 同步过来的 md

用模板 **政策摘要-Hermes** 手动套一次，或保持 frontmatter 含 `tags: 政策规范`。
