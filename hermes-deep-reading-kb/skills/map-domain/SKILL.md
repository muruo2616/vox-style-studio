# /map-domain — 知识导航图（Step 1）

## 目标

生成或更新 `maps/00-知识导航-总图.md`，作为人生「知识版导航图」。

## 流程

1. 读取 `~/.hermes/memories/USER.md` 中的领域与目标表
2. 若 `maps/00-知识导航-总图.md` 已存在，先摘要现有结构，再询问用户要**新增 / 调整 / 合并**哪一块
3. 输出 **Mermaid mindmap** 或 **Markdown 多级列表**（以 USER.md 偏好为准）
4. 每个一级领域下至少包含：`目标` `兴趣子主题` `在读/计划` `关联笔记数（可估）`
5. 写入文件后，提示用户更新 `MEMORY.md` 中的「当前版本」与「本季度焦点」

## 输出模板（Markdown）

```markdown
---
title: 知识导航-总图
version: v0.x
date: YYYY-MM-DD
tags: [导航图, 知识库]
---
```

## 注意

- 不要一次铺太细；先 3–5 个一级领域，二级随精读生长
- 完成后建议用户发社群征求意见（外部反馈）
