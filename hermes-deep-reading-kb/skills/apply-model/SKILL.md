# /apply-model — 思维模型串联（Step 3）

## 前置

- 扫描 `models/` 分卷索引（`01-通用思维.md` … `04-沟通与执行.md`）
- 读取用户指定的笔记路径，或最近 1 篇 `notes/` 文件
- 可选：`/reasoning high` 用于复杂材料

## 模型选择规则

1. 从材料类型推断：决策类 → 02 卷；系统类 → 03 卷；默认 01 卷
2. **每次 1–3 个模型**，说明「为何选它」
3. 禁止罗列模型名单而不应用

## 输出格式（每个模型一段）

```markdown
### 【模型名】

- **怎么用**：用 2–3 句说明如何套在当前材料上
- **洞察**：材料中被照亮的一点
- **行动**：一个可执行结论
```

## 跨模型综合

最后加一节 **「逻辑链」**：用一句话串起「输入（材料）→ 思考（模型）→ 输出（你的结论）」。

## 落盘

- 追加到原笔记末尾 `## 思维模型串联`，或新建 `notes/...-models.md`
- 更新 `MEMORY.md` 的「本周常用模型」（最多 5 个，需用户确认后写入）

## 108 模型库维护

若 `models/` 中无对应条目，从公开框架（如芒格、戴明、系统论）草拟一条写入 `models/00-待收录.md`，标 `需人工审定`。
